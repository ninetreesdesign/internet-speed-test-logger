Speed Monitor -- Quick Reference

Opening the app

Double-click speed_monitor.html in the Dropbox folder Internet Speed Test Log. No server is needed. Keep it with vendor/ and always open it in the same browser, because the log is stored per browser.

How it works

The background collector tests on each computer, with or without this page open, and logs to Dropbox. This page shows those logs from every computer and reloads them every 5 minutes. Ping Test and Full Test run immediately in this browser and are kept in this browser only.

Scheduling

Set in collector_settings.json: a connectivity check every minute and a speed test about every 4 hours. Ping points from the collector are 15-minute medians for the last 8 days and hourly medians before that.

Data

Collector logs are in data/ in the Dropbox folder. Export saves only this browser's manual tests; Import adds a CSV to this browser.

Speed test source

M-Lab NDT7 -- download and upload using M-Lab's official browser client. Each full test is one sustained NDT7 run (not a 3-pass average). Both browser test types report the median of ten Cloudflare HTTP latency probes before bandwidth testing; zero, invalid, timed-out, and over-2000-ms samples are excluded. The three URL targets are independent connectivity witnesses; their response times are retained only in the diagnostic URL log and are not website-speed measurements.
