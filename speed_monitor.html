Speed Monitor -- Quick Reference

URL -- open this in your browser

http://localhost:8765/speed_monitor.html

Requires the local server to be running first (see below). file:// URLs will not work -- the speed test API requires a server origin.

Starting the server

Mac / Linux: in Terminal:
cd ~/Dropbox/Internet\ Speed\ Test\ Log && python3 -m http.server 8765
Windows: in Command Prompt:
cd "%USERPROFILE%\Dropbox\Internet Speed Test Log" && python -m http.server 8765
Then open http://localhost:8765/speed_monitor.html

First use on a new machine

1. Enter a machine name (top-left field) -- labels all log rows from this device
2. Set Ping and Full test intervals (click field, type new value, press Enter)
3. Dashboard auto-starts -- ping fires immediately, full test follows on first ping success

Controls

Full TestRun a manual full speed test now
Pause / ResumeSuspend or resume all scheduling
StopHalt without closing the page
ExportDownload CSV log file

Log row symbols

● greenFull speed test -- ok
x redSpeed test or ping -- failed
. bluePing check -- ok (ping only, no speeds)
# grayState event (STARTED, PAUSED, OFFLINE...)

Click any row for full detail popup.

Scheduling

Ping check runs every N min (default 15). Full speed test runs every M min (default 30) but only fires after a successful ping. On ping failure: retries every 1 min up to 5x, logs OFFLINE / RECOVERED events, then reverts to normal schedule.

Data

Saved in browser localStorage -- persists across restarts. Export CSV regularly to keep a permanent copy. Log files named speedtest_<machine>_<year>-Q<n>.csv -- one per machine per quarter.

Speed test source

Cloudflare speed.cloudflare.com -- ping, download, upload. Each full test runs 3 passes and averages the results.
